## 踩坑记录 🕳️

### 坑1：gateway stop 后无法 start
- **现象**：`openclaw gateway stop` 之后，start/restart 都报 `Gateway service not loaded`
- **原因**：stop 会把 LaunchAgent 服务卸载掉
- **解决**：需要重新 `openclaw gateway install`
- **正确做法**：要重启直接用 `openclaw gateway restart`，不要先 stop 再 start

### 坑2：Config token differs from service token
- **现象**：restart 提示 token 不一致
- **原因**：改了配置文件但系统服务还用旧 token
- **解决**：`openclaw gateway install --force` 同步 token

### 坑3：tools.profile = "messaging" 导致工具不可用 ⭐最坑
- **现象**：AI 说"我没有 write 工具"，无法创建文件、执行命令
- **原因**：openclaw.json 里 `"tools": {"profile": "messaging"}` 限制了工具范围
- **解决**：删掉 `"tools"` 配置项，或改成 `"profile": "full"`
- **教训**：onboard 默认可能带这个限制，一定要检查！
