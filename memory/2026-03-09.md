### opx-auth skill 优化
- **问题**：AppleScript 无法访问 Chrome 标签页（OpenClaw 启动的独立 Chrome 实例抢占了 AppleScript 连接）
- **解决**：必须显式指定 `profile: "chrome"` 使用 Browser Relay 扩展
- **关键**：所有 browser 调用必须写 `profile: 'chrome'`，不能使用默认的 `profile: 'openclaw'`
- **文件位置**：`~/.openclaw/workspace/skills/opx-auth/`
