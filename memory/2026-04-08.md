## nail_collector.py 全链路修通（11:30）

**背景**：nail 采集链路自 03-30 起长期失效（CDP timeout、callFunctionOn 报错）。

**根因链路**：
1. Chrome 启动带 `--test-type` → CDP Runtime/Page 域 HTTP 500
2. 旧 browser.py 用 Playwright，沙箱里死锁
3. 新 browser.py（websockets CDP）复用旧 tab → tab 有残留 WS 连接 → Runtime.enable timeout
4. 图片 URL 从 DOM 拿到，urllib 直接下载 → 403（xhscdn.com 防盗链）

**解法**：
- `force_new=True`：强制新建干净 tab，不复用旧 tab
- document.cookie 拿明文 cookie，urllib 下载时带上
- env 文件的值有双引号，load_env 里加 strip('"') 去引号
- Venus 响应 `data` 字段是字符串 URL，不是 `{"url": ...}`，修了 `upload_to_venus`
- Supabase anon key 在 env 里（不是 SERVICE_KEY），修了 `insert_supabase`

**最终结果**：target=3，下载 9 张，上传 Venus 9 张，入库 3 条（nail + nail-face 分流正常）
