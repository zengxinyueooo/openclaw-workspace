宝宝问为什么本地 claw 换票一直 500，以及为什么沙盒能成功而本地不行。

### 根本原因梳理

1. **换票地址没问题**：`https://supabase.cloud.test.sankuai.com` 实际可用（前天和今天沙盒都成功换票）。本地 500 可能是临时故障或 MOA 未登录。

2. **IDENTIFIER 差异**：
   - 换票脚本依赖 `get-identifier.sh`，优先读环境变量 `$IDENTIFIER`，否则读 `/root/.openclaw/config/sandbox.json`。
   - 沙盒自动生成了 `sandbox.json`，identifier 为 `6e862673beea5cdcccef`。
   - 本地 claw 没有这个文件，所以换票脚本报错找不到 identifier。
   - **解决方案**：本地创建 `~/.openclaw/config/sandbox.json`，内容 `{"identifier": "本地自己的identifier"}` 或用 `IDENTIFIER=xxx` 环境变量传入。但注意 identifier 可能是实例绑定的，沙盒的不一定能在本机用。

3. **mcporter 丢失问题**：
   - 前天用的是 `/root/.npm/_npx/bdbf2deecdd22bc5/node_modules/.bin/mcporter`（npx 缓存）。
   - 今天沙盒 npx 缓存被清空，mcporter 不存在了。
   - 内网 npm（`r.npm.sankuai.com`）和公网 npm 都 403 无法安装 mcporter。
   - openclaw skills 列表中 mcporter 状态为 `✗ missing`，说明需要单独安装。

4. **MCP 直连协议**：
   - mcphub 支持 SSE transport，需要先 GET 建立 SSE 连接拿 `sessionId`（endpoint 事件返回）。
   - 然后 POST `?sessionId=xxx` 发送 jsonrpc 消息。
