# 人工介入节点.md

## 必须人工确认的场景

### 1. 选题方向确认
- **触发时机**：Topic Researcher 提交选题列表后
- **等待动作**：Orchestrator 汇总并转达皮皮
- **确认内容**：
  - 这批选题是否值得做？
  - 优先级排序
  - 是否有不合适的需要剔除？
- **超时处理**：等待24小时无响应，暂停任务并提醒

### 2. 内容草稿确认
- **触发时机**：人工完成内容生产，提交到 drafts/ 后
- **等待动作**：Orchestrator 展示预览并请求确认
- **确认内容**：
  - 标题是否 OK？
  - 图片是否满意？
  - 文案是否需要修改？
  - 话题标签是否合适？
- **可选操作**：
  - "确认发布" → 进入发布流程
  - "修改：[具体意见]" → 返回修改
  - "放弃" → 标记废弃

### 3. 发布执行授权
- **触发时机**：草稿确认后，准备发布前
- **等待动作**：Orchestrator 请求最终授权
- **确认内容**：
  - 确认目标账号
  - 确认发布时间（立即/定时）
  - 最终确认发布
- **重要**：Publisher 必须有此授权才会执行

## 可能人工介入的场景

### 4. 原子能力缺失
- **触发时机**：流程中需要的能力尚未建设
- **处理方式**：
  - Orchestrator 说明："XX能力尚未就绪，需要人工完成"
  - 皮皮完成后，告知 Orchestrator 继续

### 5. 异常处理
- **触发时机**：Worker Agent 失败、超时、状态异常
- **处理方式**：
  - Orchestrator 汇报异常详情
  - 皮皮决策：重试/跳过/人工介入/终止

## 确认方式

### 标准确认
皮皮回复格式：
- `确认` / `OK` / `可以` → 正向确认
- `修改：[具体意见]` → 返回修改
- `放弃` / `跳过` → 终止当前任务
- `暂停` → 暂停流程，等待进一步指令

### 紧急联系
如遇到必须立即决策的情况：
- Orchestrator 通过爪爪立即转达
- 标注【需立即确认】
