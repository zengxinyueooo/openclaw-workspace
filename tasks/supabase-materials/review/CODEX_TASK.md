优化 tasks.html 的动物团展示区域，要求如下：

## 1. 三层组织架构

展示清晰的层级关系：

第一层（最顶部，最大）：
- 👤 皮皮 — "MCN 动物团创始人，所有任务的最终决策者"

第二层（中间）：
- 🦊 爪爪 — "首席运营官，不亲自干活，只负责调度派活"

第三层（底部，一排）：
- 🦅 鹰眼 — "策划部，负责选题研究和热点追踪"
- 🐿️ 松鼠 — "采集部，负责全网素材搜集和整理"
- 🐝 蜜蜂 — "生产部，负责AI生图和内容创作"
- 🐜 蚂蚁 — "运营部，负责数据分析和评论管理"

层与层之间要有连线或箭头表示汇报关系。
每个角色下面有一行小字自我介绍。

## 2. 炫酷动效（花里胡哨越好）

要那种一眼觉得"卧槽好牛"的感觉：
- 背景：深色星空/粒子效果，用 canvas 或纯 CSS 实现
- 角色卡片：玻璃拟态(glassmorphism)，半透明毛玻璃质感
- 发光效果：每个角色有对应颜色的光晕(glow)
  - 皮皮=橙色, 爪爪=蓝色, 鹰眼=紫色, 松鼠=绿色, 蜜蜂=金色, 蚂蚁=红色
- 连线动画：层级间的连线有光点在上面流动（像电路/数据流）
- 入场动画：页面加载时角色依次从不同方向飞入
- 悬浮效果：hover 时卡片放大 + 光晕增强 + 微微抖动
- emoji 动画保留但要更夸张：
  - 鹰：大幅度翱翔
  - 松鼠：疯狂囤货的感觉
  - 蜜蜂：高速 zigzag
  - 蚂蚁：排队行军
  - 爪爪：优雅摇尾巴
  - 皮皮：皇冠闪烁感
- 点击角色仍然触发筛选功能
